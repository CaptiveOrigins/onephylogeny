# @captiveorigins/onephylogeny-engine

OnePhylogeny engine: runs profiles end to end with immutable run records and structured logs: fetch, anchor, gate, build panels, validate, test samples and build trees through replaceable ports.

See the [repository](https://github.com/CaptiveOrigins/onephylogeny) for documentation.

## JSON Schemas

`schemas/examples.schema.json` and `schemas/dataset.schema.json` describe a built panel's `examples.json` and `dataset.json` (see `onephylogeny verify`).
