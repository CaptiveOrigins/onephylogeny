# @captiveorigins/onephylogeny-react

Server-renderable views of sample results, panel coverage, validation, run logs and outgroup suggestions, with a compact lineage card for record pages.

Import `@captiveorigins/onephylogeny-react/styles.css`. Colors are CSS variables prefixed `--ophy-`.

See the [repository](https://github.com/mgilardi/onephylogeny) for documentation.
