# 0004 — Apache-2.0 with a NOTICE file

**Context.** The owner wants open source with attribution. MIT already requires keeping the copyright notice, but it is easy to overlook and says nothing about patents. No common permissive license requires visible credit in a product's interface.

**Decision (proposed).** Apache-2.0: redistributions keep the license and NOTICE, modified files must say so, and it includes a patent grant. Sister tools stay MIT unless the owner decides otherwise; versions already published stay MIT either way.

**Consequences.** Requires legal review, along with the GPL and AGPL tools bundled in the desktop app. A license requiring on-screen credit would need a less common option and should be a deliberate choice.
